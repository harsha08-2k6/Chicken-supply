# Chicken Supply Management System

A full-stack system for managing chicken supplies between Sri Venkateswara Chicken Centre and its customers (restaurants) and workers.

## Tech Stack
- **Backend:** Java 21, Spring Boot 3, Spring Security (JWT), Spring Data JPA, MySQL 8
- **Frontend:** HTML5, CSS3 (Vanilla), JavaScript, Bootstrap 5

## Setup Instructions

1. Configure your MySQL database credentials in `src/main/resources/application.properties`.
2. Run the Spring Boot backend using your IDE or via Maven: `./mvnw spring-boot:run`.
3. Serve the `frontend/` directory using a local web server (e.g., VS Code Live Server or python HTTP server).

More documentation will be added as the project progresses.
